Client: host-driven continuous requests

Acquire does not schedule. Start resumes with fresh host metrics and schedules one browser callback at a time. Stop/hidden cancels and suspends; returning visible requires explicit Start. Errors/native loss stop scheduling. Dispose releases the session, including an unwanted late acquisition. Counts are submissions, not FPS or displayed-frame measurements. CSS resize and browser DPR changes are forwarded to Render; hidden/zero size requires explicit Start after restoration. Unmount removes host observers/listeners and releases graphics; reload to mount again. The scene remains the same opaque blue clear, not Scene rendering.
