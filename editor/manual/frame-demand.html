Editor: on-demand redraw

Mount installs the Editor host only. Start acquires real Render graphics, applies measured CSS size and browser DPR, then schedules one initial frame. Invalidate requests share one callback. Resize/resume configure before an on-demand request. Stop/hidden/zero-size suspends; resume is explicit. Unmount cancels callbacks, disconnects observers/listeners and releases held or late graphics. Canvas and authored content remain host-owned. The clear frame is not Scene rendering.
